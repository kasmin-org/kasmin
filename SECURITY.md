# Security policy

Kasmin processes personal data of minors, including health data. We take security reports seriously.

## Reporting a vulnerability

Please report vulnerabilities **privately** via GitHub: *Security* tab of this repository → *Report a
vulnerability* (private vulnerability reporting). Do not open a public issue.

Please include the affected version, a description, steps to reproduce and the possible impact. You will receive
an answer as soon as possible; we will coordinate a fix and a release before any public disclosure.

## Supported versions

Security fixes are provided for the latest MINOR release. Before 1.0, only the latest release is supported.
