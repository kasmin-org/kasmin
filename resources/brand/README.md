# Kasmin brand assets

Default logo of Kasmin. Organisations can replace the logo shown in their portal and admin interface in the
settings; these files are the default.

| Colour | Hex | Use |
|---|---|---|
| Kasmin green | `#1DA029` | hexagon, theme colour |
| Summer yellow | `#F5A524` | check mark, accents |
| Deep green | `#14501C` | wordmark on light backgrounds |
| White | `#FFFFFF` | K, text on dark backgrounds |

Font of the wordmark and recommended UI font: Lexend (SIL Open Font License 1.1, see `Lexend-OFL.txt`).
The SVG files contain outlines, no font is required to display them.

Files: `kasmin-symbol*`, `kasmin-logo-horizontal*`, `kasmin-logo-stacked*`, `kasmin-wordmark*`, each in colour,
`-on-dark`, `-black` and `-white`. Favicons and the web manifest are in `public/`.
